# Student Result Analysis Project

A data analysis project using Python to explore and visualize student exam performance.

The project uses the **Students Exam Scores** dataset from Kaggle and analyzes factors such as parental education, marital status, transport, ethnicity, test preparation, and student scores.

### Tools & Libraries
- Python
- Pandas — data cleaning and analysis
- Matplotlib — data visualization
- Seaborn — statistical visualization

- Exploratory Data Analysis (EDA)
- Student score distributions
- Categorical variable analysis
- Box plots, bar charts, pie charts, heatmaps, and other visualizations
- Analysis of factors related to Math, Reading, and Writing scores
